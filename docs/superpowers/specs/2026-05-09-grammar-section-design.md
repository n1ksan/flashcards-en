# Раздел грамматики с правилами и упражнениями

**Дата:** 2026-05-09
**Контекст:** Telegram Mini App `D:\quizlet` — flashcards-приложение на чистом HTML/CSS/JS, размещённое на GitHub Pages, с Telegram CloudStorage для прогресса.

## Цель

Добавить в приложение раздел «Грамматика» с правилами уровня A1–B2 и небольшими упражнениями на вписывание в пропуск. Чтобы пользователь мог сначала прочитать правило, а затем сразу закрепить его на 5–7 вопросах.

## Решения, принятые в брейнсторминге

| Вопрос                     | Решение                                                            |
|----------------------------|--------------------------------------------------------------------|
| Размещение                 | Новая вкладка в нижней навигации (4-я по счёту, рядом со Статистикой) |
| Уровень и объём            | A1–B2, ~18 тем                                                     |
| Структура темы             | Правило + 5–7 упражнений подряд, итоговый экран                    |
| Тип упражнений             | Только вписывание в пропуск (текстовый ввод)                       |

## Что меняется и что нет

### Меняется

- [index.html](../../../index.html) — добавляется четвёртая кнопка нижней навигации, новый view `#view-grammar`, JS для вкладки тем / урока / упражнений.
- Новый файл [data-grammar.js](../../../data-grammar.js) — массив тем с правилами и упражнениями.
- Stats-view — добавляется отдельная секция «Грамматика» (X из N тем пройдено).

### Не меняется

- Существующие наборы (thematic / b2 / idioms) и их хранилище.
- Логика flashcards: карточки, раунды, тест, список — без изменений.
- API бота, cache-busting через `?v=...` — без изменений.
- CloudStorage-обвязка `storage.get/set` — переиспользуем как есть.

## Архитектура UI

### Нижняя навигация (4 кнопки)

```
📁 Папки     🃏 Карточки     📚 Грамматика     📊 Статистика
```

`flex:1` — кнопки сами займут по 25%.

### View `#view-grammar`: три состояния

1. **Список тем** (главный экран вкладки)
   - Группировка по уровням: A1, A2, B1, B2.
   - Каждая тема — карточка (название, краткое описание, бейдж уровня, индикатор пройдено/нет, последний результат если был).

2. **Урок (правило)** — открывается по тапу на тему
   - Заголовок темы, бейдж уровня.
   - Текстовое объяснение правила.
   - Таблица форм / схема (HTML-блок).
   - 2–4 примера с переводом.
   - Кнопка «▶ Начать упражнения» внизу.
   - Кнопка «‹ Назад к списку» в шапке.

3. **Упражнение** — после нажатия «Начать»
   - Прогресс N / total и прогресс-бар.
   - Предложение с пропуском: `She ___ to school every day.`
   - Подсказка под предложением: `(go)` — базовая форма для трансформации.
   - Текстовый input + кнопка «Проверить» (или Enter).
   - После проверки: зелёная/красная подсветка, правильный ответ если ошибся, перевод предложения целиком, кнопка «Следующее».
   - В конце — итоговый экран: счёт, кнопки «Повторить», «К правилу», «К списку тем».

### Нормализация ответов

Сравнение нечувствительно к регистру и лишним пробелам, апострофы `'` и `'` приравниваются. `answers` — массив, чтобы принимать варианты типа `["doesn't go", "does not go"]`.

```js
function normalize(s) {
  return s.trim().toLowerCase().replace(/['']/g, "'").replace(/\s+/g, ' ');
}
function checkAnswer(input, answers) {
  const n = normalize(input);
  return answers.some(a => normalize(a) === n);
}
```

## Хранение прогресса

Один ключ `grammar_progress` в Telegram CloudStorage:

```json
{
  "present_simple":     { "best": 6, "total": 6, "attempts": 2 },
  "past_simple":        { "best": 4, "total": 6, "attempts": 1 }
}
```

- `best` — лучший результат пользователя по теме.
- Тема считается «пройденной», если `best === total`.
- Attempts — для будущей статистики/мотивации.

## Список тем

**MVP (1 тема):** Present Simple (A1) — все элементы пайплайна, чтобы проверить UX на устройстве.

**Полный план (~18 тем) — после валидации MVP:**

- **A1 (5):** to be, Present Simple, Articles (a/an/the), Possessives ('s, my/your/...), Plural nouns
- **A2 (5):** Present Continuous, Past Simple, Future (going to / will), Comparatives & Superlatives, Modals (can/could/must)
- **B1 (4):** Present Perfect, Past Continuous, Conditionals 0 & 1, Used to
- **B2 (4):** Past Perfect, Conditionals 2 & 3, Reported Speech, Passive Voice

В каждой теме — 5–7 упражнений. После полного развёртывания — ~100 упражнений.

## CSS / визуальная консистентность

- Переиспользуем существующие токены (`--surface`, `--accent`, `--green`, `--red`, `--radius`).
- Карточки тем — стиль `.set-stat-card` / `.folder-card`, чтобы не разводить новый компонент.
- Input для ответа — стиль аналогичен `.search-bar`, но без иконки поиска.
- Бейджи уровня (A1/A2/B1/B2) — мелкий пилл с цветной заливкой:
  - A1 — зелёный, A2 — синий, B1 — фиолетовый, B2 — оранжевый.

## Открытые вопросы — закрыты

- ~~Где жить разделу?~~ → новая вкладка bottom-nav
- ~~Уровень?~~ → A1–B2
- ~~Структура темы?~~ → правило + 5–7 упражнений подряд
- ~~Тип упражнений?~~ → только вписывание
- **Прогресс:** хранится по `id` темы, тема «пройдена» при 100% последнего лучшего результата
- **Стат-вкладка:** добавляется секция «Грамматика: X / N тем»

## Не входит в этот пакет (можно потом)

- Аудио-произношение примеров.
- Spaced repetition по упражнениям, в которых ошибся.
- Тренажёр «вперемешку» (упражнения из всех тем).
- Поделиться результатом темы.
- Изменение порядка упражнений / больше типов (drag-and-drop, transformation).
